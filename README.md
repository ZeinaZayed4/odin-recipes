# Odin Recipes

A simple multi-page recipe website built with HTML, as a part of [The Odin Project's Foundations course](https://www.theodinproject.com/lessons/foundations-recipes).

- The home page (`index.html`) lists links to every recipe.
- Each recipe page has an image, a description, an ingredients list, and numbered steps.
- Every recipe page links to the home page.

## Folder Structure

```text
odin-recipes/
├── index.html
├── README.md
├── images/
│   ├── homemade-cinnamon-rolls.jpg
│   ├── koshary.jpg
│   └── sheetpan-hot-honey-chicken-bowls.jpg
└── recipes/
    ├── homemade-cinnamon-rolls.html
    ├── koshary.html
    └── sheetpan-hot-honey-chicken-bowls.html
```

## How to View

- **Live site:** [Odin Recipes](https://zeinazayed4.github.io/odin-recipes/)
- **Locally:** open `index.html` in your web browser.
